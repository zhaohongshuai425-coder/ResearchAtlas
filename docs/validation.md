# 验证范围

本项目的自动回归覆盖收件去重、身份冲突、索引/锚点回放、阶段记录、只读工具桥、版本绑定、图谱审阅、安装升级/回退和移交恢复等工程行为。测试数据是临时合成夹具，不调用模型API、不启动科研训练。

公开版基于本地1.2.8工具；该基线的340项回归曾在同一Windows电脑的Python3.10和3.12通过。公开打包涉及默认排版资料、许可分发和文档调整，须以当前build_report.json及CI实际结果核验，不能直接沿用旧版本全部验收。

实际PDF解析/页图渲染已用合成内容的有效PDF串联检查过；这不等于完整真实论文精读、半成品科研优化或论文撰写效果通过。

Codex原生发现、本地执行、真实模型往返及科研判断是不同层面。DeepSeek/Harness的目录和JSON桥有离线验证，完整原生模型闭环及实体第二台电脑的代表任务仍待验收。Linux/macOS或其他Python版本仅在对应CI/实机结果实际通过后声明该范围。

状态、指纹和审阅字段齐全不构成科学真实性认证；重要论断仍回到原文、条件及实际数据。内部路径和原始验收日志不随公共包发布，公开摘要保持这些边界。
