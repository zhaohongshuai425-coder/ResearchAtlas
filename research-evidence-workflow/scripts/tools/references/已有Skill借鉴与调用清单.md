# 工作流来源与可选集成

本项目把文献、图谱、审阅、验证和写作记录串联起来。参考工作流和本项目工具的职责分开：本包提供当前脚本，其他Skill只有在宿主实际安装、任务适用时才按需加载。

| 环节 | 可参考的工作流 | 本包中的对应职责 |
|---|---|---|
| 文献搜集、筛选 | literature-review | 保存检索、来源、纳排、版本和覆盖边界 |
| 问题和假设 | hypothesis-generation | 区分观察、假设、替代解释与待验证预期 |
| 实验计划 | experimental-design | 明确单位、对照、分组、混杂及停止条件 |
| 统计、图件和写作 | 宿主可用的统计、科研绘图、写作或Office工具 | 按任务实际能力执行并保存可核对产物 |
| 来源与版面 | 宿主PDF/文档能力 | 回查原页、公式、图表和最终渲染 |

前三项工作流来自K-Dense Scientific Agent Skills；具体来源及MIT署名见相邻工具目录的THIRD_PARTY_NOTICES.md。其他历史参考名称只保留在来源登记，不捆绑其原文件或假定可用。

阅读参考不等于已经运行原工具、完成全文精读或取得有效结果。只加载当前任务需要的规则，外部模板和模型按各自条款另行提供。
